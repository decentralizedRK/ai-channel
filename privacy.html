Privacy Policy

App: Zero to AI Engineer Uploader · Last updated: 18 October 2026

Who uses this app

Zero to AI Engineer Uploader is a private, internal tool. It is used only by the owner of the "Zero to AI Engineer" YouTube channel to publish that channel's own videos. It is not offered to, and has no other users.

What data the app accesses

With the channel owner's permission (Google OAuth), the app uses the YouTube Data API to:

  • upload videos and thumbnails to the owner's own channel;
  • add captions, playlist entries and comments to those videos;
  • read basic information about the owner's own channel (for example, its name), to confirm it is uploading to the right channel.

The app does not access, collect or store data about any other YouTube users or viewers.

How data is stored

The OAuth credentials (client ID, client secret and refresh token) are stored as encrypted secrets in the owner's private GitHub repository and are used only by automated workflows that publish the channel's videos. No personal data is sold, shared with third parties, or used for advertising.

Google API Services User Data Policy

This app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. It also complies with the YouTube Terms of Service and the Google Privacy Policy.

Revoking access

Access can be revoked at any time from Google Account → Third-party connections. When access is revoked, the stored refresh token stops working.

Contact

For questions about this policy, contact the channel owner through the "Zero to AI Engineer" YouTube channel's About page.
